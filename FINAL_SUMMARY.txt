================================================================================
⏱️ PERFORMANCE TIMING
================================================================================

The 'timeTakenMs' field measures time from message publish request to
receiving Kafka broker acknowledgement.

Includes:
  • Message serialization
  • Network transmission to broker
  • Broker processing
  • Replication (if acks=all)
  • Response transmission back

Typical Values:
  • 10-20ms   = Local Kafka, single partition
  • 40-60ms   = Standard configuration
  • 80-150ms  = Multiple replicas, full durability
  • >200ms    = Investigate (network/broker issues)

Use Cases:
  • Monitor end-to-end latency
  • Analyze configuration impact
  • Identify performance bottlenecks
  • Compare different settings
