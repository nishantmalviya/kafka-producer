🔐 CONFIGURATION QUICK REFERENCE
================================================================================

LOCAL DEVELOPMENT (No Auth):
  spring.kafka.bootstrap-servers=localhost:9092
  kafka.topic.name=my-topic

JAAS Authentication (SASL/PLAIN):
  spring.kafka.properties.security.protocol=SASL_SSL
  spring.kafka.properties.sasl.mechanism=PLAIN
  spring.kafka.properties.sasl.jaas.config=org.apache.kafka.common.security.plain.PlainLoginModule required username="user" password="pass";

SSL/TLS Certificates:
  spring.kafka.properties.ssl.truststore.location=file:/path/to/truststore.jks
  spring.kafka.properties.ssl.truststore.password=password
  spring.kafka.properties.ssl.keystore.location=file:/path/to/keystore.jks
  spring.kafka.properties.ssl.keystore.password=password

Producer Settings:
  spring.kafka.producer.acks=all                      # Highest durability
  spring.kafka.producer.retries=3                     # Retry attempts
  spring.kafka.producer.compression-type=snappy       # Compression

Environment Variables (Recommended for Production):
  export SPRING_KAFKA_BOOTSTRAP_SERVERS='kafka.example.com:9093'
  export KAFKA_JAAS_CONFIG='org.apache.kafka.common.security.plain.PlainLoginModule required username="user" password="pass";'
  java -jar kafka-producer-1.0.0.jar

📊 PERFORMANCE TIMING
================================================================================

The 'timeTakenMs' field in responses shows time from message send to Kafka
acknowledgement. This includes:

  1. Message serialization
  2. Network transmission to broker
  3. Broker processing
  4. Replication (if acks=all)
  5. Response transmission back

Typical values:
  - acks=1, no replication: 10-20ms
  - acks=all, single replica: 40-60ms
  - acks=all, 3 replicas: 80-150ms
  - With compression: add 10-30ms

Use this metric to:
  - Monitor end-to-end latency
  - Analyze impact of configuration changes
  - Identify performance bottlenecks
  - Understand replication overhead
